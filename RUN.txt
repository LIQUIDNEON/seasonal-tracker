Seasonal Tracker
===============

Install as a desktop widget
  git clone https://github.com/LIQUIDNEON/seasonal-tracker.git
  cd seasonal-tracker
  chmod +x install-desktop.sh launch.sh launch-window.sh
  ./install-desktop.sh

KDE Plasma
  Right-click desktop → Add Widgets → Seasonal Tracker
  Resize to the screen slice you want
  If missing: kquitapp6 plasmashell && kstart6 plasmashell
  Needs: sudo dnf install -y qt6-qtwebengine

GNOME / other
  ./launch-window.sh
  Keep the window on top from the title-bar menu
  Backend already autostarts via systemd --user

Dev
  ./launch.sh
  ./launch.sh --no-browser
  python3 widget.py --port 9000

Service
  systemctl --user status seasonal-tracker.service
  systemctl --user restart seasonal-tracker.service

Uninstall widget packaging
  ./install-desktop.sh uninstall

First-time setup
  1. Click Add shows
  2. Pick the current or next season (or search any title)
  3. Click posters to pin them — outlined cards are already pinned
  4. Use Today / This week / Next week / Following / My shows
  5. Click an episode square to mark it watched (click again to unmark)
  6. Rows ↔ Stacks toggles the two remaining-episode layouts

Data
  Titles, posters, sub air times: AniList (MAL ids stored on every show)
  English dub air times / dubbed episode counts: AnimeSchedule via AniSchedule feeds
  Your pins and watch counts: ~/.config/seasonal-tracker/library.json
